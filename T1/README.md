Para ejecutar la parte de la experimentación se debe situar en la carpeta del apartado correspondiente. Por ejemplo, para revisar la parte 1 se debe ir al directorio Parte_1. Estando situado, se puede ejecutar desde la terminal el archivo deseado usando : python {nombre_archivo.py}.

También se puede ejecutar en visual studio con la herramienta "Run Python File" (donde está el play).

PD: Existen archivos python que al ejecutar suelen demorar unos segundos, pero sí funcionan.
